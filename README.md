## 🚀 Getting Started Locally

Because this project uses the Tailwind Play CDN, **no complex build tools or Node.js installations are required**!

1. Clone or download this repository to your local machine.
2. Ensure both `index.html` and `main.js` are in the same folder.
3. Double-click `index.html` or open it with your favorite browser (or live server extension in VS Code).
